# 0002: Frontend Stack with Vite, React (TypeScript), Tailwind CSS, and TanStack Query

For the VinDining user interface and staff management portals, we choose Vite + React 18/19 with TypeScript, Tailwind CSS, Lucide Icons, TanStack Query (React Query) for server state caching, and Zustand for lightweight global client state. This setup provides fast build times, high customization flexibility for luxury fine dining aesthetics, and robust caching/synchronization with the .NET backend.
