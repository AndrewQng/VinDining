# 0001: Backend Clean Architecture with .NET 9 and SQL Server

For the VinDining Fine Dining Management System, we choose .NET 9 with Clean Architecture (Domain, Application, Infrastructure, API) and SQL Server with EF Core Code-First. This ensures clear separation of concerns, testability, enterprise-grade identity/role management via ASP.NET Core Identity, and seamless CQRS/MediatR pipeline behaviors (validation, logging, transactional consistency).
